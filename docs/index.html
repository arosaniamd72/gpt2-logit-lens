How one layer works

The weights are fixed — training set them once, and running the model never changes them. What changes is the residual stream: a running vector that enters as a plain word and gets edited, layer by layer, into a next-word prediction.

Residual stream — the running notepad. Enters as the word, leaves as the prediction. It is the amber column in the viewer below.
Attention write — reaches back to earlier words and pulls in what is relevant: "this position should look at France." The violet column below.
MLP write — recalls associations for the current position. Layer 9's MLP voting capital cities is this step. The teal column below.

How this works

When you press Run, GPT-2 small (124M parameters) runs on a small server and sends back every layer’s readings; if the server can’t be reached, the model (fp16) downloads once and runs entirely on your device in a background thread instead. Each layer's vector is projected through the model's own final LayerNorm and unembedding to read out what it "predicts", with no server round-trip.

The per-layer MLP write column is why this is a from-scratch forward pass rather than an off-the-shelf runtime: no packaged GPT-2 exposes each layer's MLP output on its own. The output is verified token-for-token against a PyTorch reference before shipping.

Compute for five tokens takes a few seconds on a laptop. Layer 11's residual read-out equals the model's actual output, which is the built-in check that the projection is correct.
