How one layer works

The weights are fixed — training set them once, and running the model never changes them. What changes is the residual stream: a running vector that enters as a plain word and gets edited, layer by layer, into a next-word prediction.

Residual stream — the running notepad. Enters as the word, leaves as the prediction. Amber in both views below.
Attention write — reaches back to earlier words and pulls in what is relevant: "this position should look at France." Violet below.
MLP write — recalls associations for the current position. It works on this position alone. Teal below.

The score starts at the prior: a fixed lean toward common tokens, the same for every prompt. It is the final LayerNorm's bias read through the unembedding, and its top tokens are “,” “the” “and” “.”. Every write then does two things. Its vote pushes the score toward one token. Its shrink comes from size: the final LayerNorm divides the stream by its size, so a write that makes the stream bigger turns down every vote before it and pulls the score back toward the prior. The running total after each row is exactly what the logit lens reads at that point, and the last row is the model's real score. Layer 0's entries are large because the embedding starts very small, so layer 0's first writes set the stream's scale.

How this works

When you press Run, GPT-2 small (124M parameters) runs on a small server and sends back every layer’s readings; if the server can’t be reached, the model (fp16) downloads once and runs entirely on your device in a background thread instead. Each layer's vector is projected through the model's own final LayerNorm and unembedding to read out what it "predicts", with no server round-trip.

Ledger. The logit lens reads the stream x as LN(x)·WU. LayerNorm centers x, divides by its size σ, scales by γ and adds a bias β. So a token's score is a content part, (x − mean)/σ · γWU, plus a prior, β·WU, that never changes. When a write c lands, the content part becomes old content × σbefore/σafter + (c − mean)/σafter · γWU. The second term is the vote; the change in the first term is the shrink. Both are exact, so the running total equals the lens reading after every write. Scores are shown relative to the average vocabulary token, or as the gap between two tokens. A gap in logits is a log-odds: +2 means the first token is e² ≈ 7.4 times as likely as the second.

Writes that only shrink. Some late writes are large but point almost entirely into directions the unembedding ignores. In “The capital of France is”, layer 11's attention write is the largest in the stack, yet it moves the vocabulary about a tenth as much as a random vector of the same size would. Its whole effect is to turn the volume down. Stolfo et al. (NeurIPS 2024) describe the same mechanism in “entropy neurons” in the last MLP layer of GPT-2 and larger models.

Before → after. Each write is shown by what it did to the stream it landed on: the stream is read through the lens just before the write and just after, and the tokens whose probability moved most are listed. An earlier version read each write through the lens on its own. A write is a displacement, though, not a location, and reading it alone produced tokens unrelated to the prompt.

The six examples were computed with GPT-2 small in PyTorch (float32). Each forward pass was checked against the library's own output, and each token's ledger was checked to sum to its real logit and to match the lens reading after every write. The in-browser engine reproduces the same numbers to within fp16 precision.

Each layer makes two writes to the residual stream: attention, then the MLP. The ledger splits each write's effect into its vote and the shrink from making the stream bigger; before → after shows how each write moved the stream's lens reading.
